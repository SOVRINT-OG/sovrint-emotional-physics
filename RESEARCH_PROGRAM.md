# Research Program: Emotional Physics

**Status:** Proposed agenda for a documented conceptual draft. The title is a project name; it is not a claim that emotion follows physical laws. No clinical use, validated measurement instrument, or empirical result is claimed. See [RESEARCH_STATUS.yaml](./RESEARCH_STATUS.yaml).

## Scope

The README describes candidate topics including state variables, affective load, relational context, feedback, and recovery. Their definitions and measurement properties remain open research questions. The project must distinguish phenomenological descriptions, candidate mathematical models, computational implementations, and independently supported empirical claims.

## Questions

1. Which constructs have operational definitions that can be distinguished from ordinary-language labels?
2. Which candidate representations are useful for a stated task, and what information do they omit?
3. How sensitive are results to context, time window, measurement method, and individual differences?
4. What observations could falsify a proposed model, rather than merely illustrate it?
5. Which work can be tested with synthetic fixtures, and which questions would require an approved human-subjects protocol?

## Planned work

- Maintain a construct ledger linking each term to a definition, source, intended use, exclusions, and evidence status.
- Compare candidate representations against cited literature without treating one model as canonical for all contexts.
- Build synthetic examples for software behavior only; label generated data synthetic and separate it from observations about people.
- For any future human-participant study, first document consent, privacy, risk review, sampling, measurement validity, and withdrawal procedures.
- Report negative and inconclusive results as well as positive results.

## Safety and evidence boundaries

Do not use this draft to diagnose, rank, infer hidden mental states, or make decisions about identifiable people. Do not collect personal emotional data in this repository. A computational test can check code behavior; it cannot by itself establish psychological validity.
